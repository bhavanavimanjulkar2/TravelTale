                                            # 🌍 TravelTale

TravelTale is a full-stack travel social media platform where users can share their travel experiences by creating posts with images, descriptions, locations, estimated costs, and visit dates. Users can explore destinations shared by others, leave reviews and ratings, and interact with travel stories through a clean and engaging interface.

The platform also features a unique **Travel History Timeline**, which organizes a user's travel posts chronologically based on the actual visit date, allowing them to visualize their complete travel journey.

## 🌐 Live Demo

🚀 Live Demo: https://traveltale.onrender.com/

---

## ✨ Features

-  Secure user authentication
-  Create, edit, and delete travel posts
-  Upload destination images using Cloudinary
-  Interactive maps powered by Mapbox
-  Search and filter travel destinations
-  Add reviews and ratings for destinations
-  Travel History Timeline based on visit dates
-  Share travel journey and export it as PDF
